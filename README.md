# Barry-Wehmiller Copilot and Sales Agent Activation

Customer-facing resource center prepared for Barry-Wehmiller Group.

- Skin: Workshop
- Audience: Approved Barry-Wehmiller and Microsoft engagement participants
- Updated: 2026-09-29
- Gate: password
- Expiry: none (explicit no expiry)

The Gameplan uses a reusable, eight-step Dynamics 365 Sales Agent launch
standard. Barry-Wehmiller-specific values are isolated in the customer launch
profile at the top of the guide.

Five business days is a target, not a guarantee. Product propagation,
customer change control, or unresolved access dependencies can extend the path;
none justify skipping a gate.

Only reviewed customer-viewable files belong in this folder. Private governance,
source evidence, internal notes, and plaintext passphrases are intentionally
stored elsewhere. A client-side gate is a display convenience, not a security
boundary for files in a public repository.
